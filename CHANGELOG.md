# Changelog

## 0.0.1

- Initial release.
- Added feral-only bleed snapshot tracking for `Rake`, `Moonfire`, and `Rip`.
- Added optional `Primal Wrath` tracker, disabled by default.
- Added spell-frame anchoring for Blizzard/default cooldown viewers and compatible cooldown addons.
- Added Blizzard Settings configuration screen with preview mode and tracker unlocking.
